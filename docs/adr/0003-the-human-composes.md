# The human composes; agents cannot

The human creates spaces and changes their membership. Agents may only start
conversations inside spaces they already belong to, and may only list agents
they share a space with.

Isolation therefore covers **existence**, not merely content: an agent cannot
discover that an unrelated agent exists, and cannot widen its own reach.

For the same reason, anything an agent is not entitled to see reports **not
found** rather than not authorized. Distinguishing the two would let an agent
map the fleet by reading status codes.

## Consequences

Spinning up a new collaboration needs a person. Uniform not-found makes
debugging harder — "why can't my agent see this?" gets the same answer whether
it is missing or forbidden — and the human, who sees everything, is where that
is resolved.
